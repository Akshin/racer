ИНСТРУКЦИЯ ДЛЯ MAC
==================

ЧТО НАЖИМАТЬ КАЖДЫЙ РАЗ
-----------------------
1. Двойной клик по файлу start.command в ЭТОЙ папке (MAC).
2. Откроется Терминал (чёрное или белое окно с текстом). ЕГО НЕ ЗАКРЫВАТЬ.
   Закрыли окно — игра и датчики сразу выключатся.
3. Сам откроется браузер на http://localhost:5173
   Если нет — откройте Chrome и вставьте этот адрес.
4. На странице нажмите «Подключиться».
5. Покрутите педали 2–3 секунды, пока не появятся цифры.
6. Один велосипед — галочка «достаточно одного тренажёра».
7. «Перейти к игре». На весь экран в Chrome: Control+Command+F.

Остановить: закрыть окно Терминала или нажать Control+C в нём.
Запустить снова — снова двойной клик по start.command (он сам гасит прошлый запуск).


ЕСЛИ ДВОЙНОЙ КЛИК НЕ ЗАПУСКАЕТ (очень часто на маке)
-----------------------------------------------------
«Программу нельзя открыть, потому что она от неизвестного разработчика»
  Не ошибка вируса. Зажмите Control, клик по start.command → Открыть → Открыть.
  Или: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

Открылся TextEdit с кашей из английских команд
  macOS думает, что это текст, а не программа.
  Откройте программу «Терминал» (Программы → Утилиты → Терминал).
  Перетащите файл start.command в окно Терминала и нажмите Enter.
  Либо в Терминале (подставьте свой путь к папке проекта):

    chmod +x /путь/к/velo-project/MAC/start.command
    xattr -d com.apple.quarantine /путь/к/velo-project/MAC/start.command

  Потом снова двойной клик.

«Permission denied»
  Та же команда chmod +x, что строкой выше.

«Node.js не найден»
  Двойной клик из Finder часто НЕ ВИДИТ Node, если его ставили через nvm.
  НАДЁЖНЫЙ СПОСОБ НА ЭВЕНТЕ:
    1. Откройте Терминал.
    2. Перетащите start.command в окно.
    3. Enter.
  Либо поставьте Node с официального сайта (см. «первый раз»).


ПЕРВЫЙ РАЗ НА ЭТОМ МАКЕ
-------------------------------------------
1) Node.js 24 или новее:
   https://nodejs.org/
   Скачайте macOS Installer. Для чипа Apple (M1/M2/M3/M4) — вариант Apple.
   Для старого мака с Intel — x64.

   Проверка: откройте Терминал, напишите:
     node -v
   Нужно v24.something.

2) Один раз в Терминале (сначала перейдите в папку проекта командой cd —
   можно перетащить папку velo-project в окно Терминала после слов cd и пробела):

     cd velo-node
     npm install
     cd ../velo-game
     npm install

3) Файл velo-node/.env — открыть Текстовым редактором. Строка SOURCE=
     mock — без датчиков, проверка картинки
     ble  — Wahoo по Bluetooth
     ant  — Wahoo по ANT+, нужен USB-свисток
   Сохранить. Запустить start.command снова.


BLUETOOTH И ДАТЧИКИ (самое больное место на маке)
-------------------------------------------------
macOS спрашивает «Терминал хочет использовать Bluetooth» — нажмите Разрешить.

Если нажали «Не разрешать» или окно не всплыло:
  Системные настройки → Конфиденциальность и безопасность → Bluetooth
  Включите тумблер у «Терминал».
  Если запускали из iTerm, Cursor или VS Code — галочка нужна У НИХ, не у Терминала.
  На эвенте запускайте ВСЕГДА одним способом: либо только двойной клик, либо только Терминал.

Датчик виден в телефоне, в игре «не найден»:
  Wahoo RPM по Bluetooth держит ОДНО подключение.
  Закройте на телефоне Wahoo, Zwift, Garmin.
  Выключите Bluetooth на телефоне на минуту.
  Покрутите педали, перезапустите start.command.

«ANT+ свисток не найден»:
  Воткните свисток ДО запуска.
  Может всплыть «Разрешить аксессуар» — разрешите.
  Кабель должен передавать данные, не «только зарядка».
  Другой порт USB / хаб без питания иногда не видит свисток — воткните в мак напрямую.


ЕСЛИ СЛОМАЛОСЬ ЕЩЁ
------------------
«Игра не ответила на http://localhost:5173»
  В окне Терминала выше будет красный текст. Часто забыли npm install.
  Или порт занят: не запускайте параллельно «npm run dev» из Cursor и start.command.

Страница есть, «нет соединения с адаптером»
  В Терминале должна быть строка про прослушивание порта 8080.
  В поле на странице: ws://localhost:8080
  На новых macOS браузер может спросить доступ к локальной сети — разрешите.

Чёрный экран дороги
  Откройте Chrome, не Safari. Safari часто хуже с графикой игры.

Мак уснул, всё отвалилось
  Системные настройки → Батарея (или Энергосбережение) → не выключать дисплей
  при питании от сети. На эвенте сразу зарядка в розетку.

npm install пишет про архитектуру / Rosetta
  Не смешивайте Node «для Intel» на маке с чипом Apple. Переустановите Node
  с nodejs.org под свой мак, затем снова npm install в двух папках.

Кто занял порт (если duplicate):
  В Терминале:
    lsof -nP -iTCP:8080 -sTCP:LISTEN
    lsof -nP -iTCP:5173 -sTCP:LISTEN
  Закройте старый запуск или просто снова start.command.


КАК ВЫГЛЯДИТ УСПЕХ

В браузере: http://localhost:5173 , соединение живое, цифры при педалях, можно войти в игру.
