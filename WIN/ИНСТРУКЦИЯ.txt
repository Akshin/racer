ИНСТРУКЦИЯ ДЛЯ WINDOWS
======================

ЧТО НАЖИМАТЬ КАЖДЫЙ РАЗ
-----------------------
1. Двойной клик по файлу start.bat в ЭТОЙ папке (WIN).
2. Появятся два чёрных окна: «Velo adapter» и «Velo game». Их НЕ ЗАКРЫВАТЬ.
3. Сам откроется браузер на странице http://localhost:5173
   Если не открылся — откройте Chrome и введите этот адрес вручную.
4. На странице нажмите «Подключиться».
5. Покрутите педали 2–3 секунды. Должны появиться цифры скорости и каденса.
6. Если велосипед один — поставьте галочку «достаточно одного тренажёра».
7. Нажмите «Перейти к игре». Полный экран: клавиша F11.

Остановить: крестик на окнах «Velo adapter» и «Velo game».
Запустить снова можно тем же start.bat — старые процессы он гасит сам.


ПЕРВЫЙ РАЗ НА ЭТОМ КОМПЬЮТЕРЕ
-------------------------------------------------
Нужен интернет.

1) Поставьте Node.js версии 24 или новее:
   https://nodejs.org/
   Скачайте Windows Installer (.msi), 64-bit.
   В установщике оставьте галочку «Add to PATH».
   После установки закройте ВСЕ окна командной строки и откройте новое.

2) Проверка: меню Пуск → введите cmd → Enter. Напишите:
   node -v
   Должно быть что-то вроде v24.x.x. Если «не является внутренней командой» —
   Node не в PATH: переустановите с галочкой PATH или перезайдите в Windows.

3) Откройте папку проекта (на уровень выше WIN). В проводнике в адресной
   строке напишите cmd и нажмите Enter. По очереди:

   cd velo-node
   npm install
   cd ..\velo-game
   npm install

   Это скачает библиотеки. Нужно один раз. Если красные ошибки — пришлите
   скрин того окна тому, кто готовил проект.

4) Датчики настраиваются в файле velo-node\.env (открыть Блокнотом).
   Строка SOURCE=
     mock  — без железа, для проверки экрана
     ble   — датчик Wahoo по Bluetooth
     ant   — датчик Wahoo по ANT+, нужен USB-свисток
   После правки сохраните файл и запустите start.bat снова.

5) Браузер лучше Google Chrome:
   https://www.google.com/chrome/


НА ПЛОЩАДКЕ: ЖЕЛЕЗО
-------------------
Bluetooth (SOURCE=ble):
- На компьютере включён Bluetooth (Параметры → Bluetooth и устройства).
- На ТЕЛЕФОНЕ закройте Wahoo, Zwift, Garmin Connect. Датчик умеет
  только одно подключение. Иначе компьютер его не увидит.
- Батарейка в датчике (CR2032), датчик не под чехлом из фольги.

ANT+ (SOURCE=ant):
- Свисток воткнут В ДО запуска start.bat.
- В окне «Velo adapter» не должно быть «свисток не найден».
- Если свисток не виден: другой USB-порт, не переходник «только зарядка».
- Garmin USB2 на Windows часто не работает, пока не поставить WinUSB:
  программа Zadig — https://zadig.akeo.ie/
  Это делается ЗАРАНЕЕ на этой же машине, не за пять минут до гостей.


ЕСЛИ СЛОМАЛОСЬ
--------------
«Node.js не найден»
  Node не установлен или компьютер не перезаходили после установки.
  Ссылка: https://nodejs.org/

Окно start.bat мигнуло и закрылось
  Запустите start.bat ещё раз и читайте текст. Часто забыли npm install.

«Игра не ответила» / в окне Velo game красным
  Чаще всего нет npm install в папке velo-game. Сделайте шаг 3 из
  «первый раз». Или порт 5173 занят другим приложением — закройте лишний
  Chrome с прошлой игрой и нажмите start.bat ещё раз.

В браузере «Нет соединения с адаптером»
  1. Живо ли окно «Velo adapter»? Там должна быть строка про ws:// и порт 8080.
  2. На странице в поле адреса: ws://localhost:8080
     Если когда-то вводили другой адрес — исправьте и «Подключиться».
  3. Не открывайте игру с телефона по Wi‑Fi, пока так не настроили сеть.
     Работает связка: этот компьютер + этот монитор.

Датчик «не привязан» / каденс ноль
  Телефон держит датчик — закройте приложения, выключите Bluetooth на телефоне
  на минуту. Покрутите педали. Перезапустите start.bat.
  Для BLE Windows: Параметры → Bluetooth включён.

Чёрный экран вместо дороги
  Откройте Chrome, не встроенный Internet Explorer. Обновите драйвер видео.
  Полноэкран F11.

Windows пишет «защитила компьютер» / SmartScreen
  «Подробнее» → «Выполнить в любом случае». Это обычный скрипт запуска, не вирус.

Антивирус удалил node.exe
  Добавьте папку проекта в исключения или временно выключите проверку папки.

PowerShell ругается на политику
  Один раз откройте PowerShell (не от администратора) и выполните:
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  Подтвердите Y. Скрипт использует PowerShell только чтобы освободить порты.

Два заезда подряд, шкала сразу «на финише»
  Зайдите в игру заново с страницы проверки — дистанция сбрасывается при входе.
